AppleMCP

Native macOS MCP server with a default-safe tool set, bounded local data access, and native approval for optional Calendar mutations and user Shortcuts.

macOS 15+ Swift MCP Protocol Local-first Safe defaults

Data Sources

Mail

Search and read the local Mail index and .emlx files. No Mail Automation fallback; source and returned body sizes are bounded.

Calendar

Search events via EventKit. Calendar mutations are a separate launch-time opt-in and require native approval for every call.

Contacts

Search your address book via Contacts.framework. Names, emails, phone numbers, addresses.

Notes

Search and read Apple Notes via Automation. Direct reads are capped at 65,536 characters and report truncation.

Reminders

Search reminder titles, notes, and list names via EventKit; filter by completion status. Due date and priority are returned as metadata, not filter arguments.

Photos

Search Photos library metadata via Photos.framework. PhotoKit calls the required TCC level read/write; these tools do not mutate the library.

Voice Memos

Search the local CloudRecordings store, read in-file transcripts, or transcribe only when an on-device speech model is available. Fresh non-empty transcripts are cached owner-only in Application Support without automatic expiry.

Apple Intelligence

Writing Tools

Optional user-created Writing Tools Shortcut. Disabled by default, open-world, and approved one call at a time.

Translation

Optional user-created Translate Shortcut with a versioned JSON contract and one-call native approval.

Image Playground

Generate an owner-only temporary PNG through the native ImagePlayground API. The caller can consume it before exact-name stale cleanup after 24 hours.

On-Device Summaries

Summarize text and extract action items with the on-device Foundation Models API. No user Shortcut; macOS 26.

Safe by Default

21 default tools

Observation and bounded local processing are available. Calendar mutation, permission UI, and user Shortcuts are absent.

Three separate opt-ins

M3MCP_ENABLE_CALENDAR_MUTATIONS, M3MCP_ENABLE_PERMISSION_UI, and M3MCP_ENABLE_USER_SHORTCUTS are resolved only at launch.

One-call approval

Every enabled Calendar mutation and Shortcut call gets its own default-deny native sheet. Approval is never reused.

Honest local boundary

The socket is owner-only, but an unsandboxed process running as the same user can normally connect. Full Disk Access raises that trust requirement.

Architecture

Claude / AI Assistant | stdio (MCP protocol) | M3MCPBridge (lightweight CLI) | bounded HTTP over Unix socket (0600) | M3MCPApp (SwiftUI, holds TCC permissions) | EventKit / Contacts / Photos / Mail Index / Voice Memos Store Speech / FoundationModels / ImagePlayground / Apple Events

Download

After maintainer review and publication, a GitHub release may provide M3MCP.app.zip and M3MCP.app.zip.sha256. The ZIP contains the app, MCP bridge, Apache-2.0 license, and retained third-party notices.

curl -LO https://github.com/GodModeAI2025/AppleMCP/releases/latest/download/M3MCP.app.zip
curl -LO https://github.com/GodModeAI2025/AppleMCP/releases/latest/download/M3MCP.app.zip.sha256
shasum -a 256 -c M3MCP.app.zip.sha256
gh attestation verify M3MCP.app.zip \
  --repo GodModeAI2025/AppleMCP \
  --signer-workflow GodModeAI2025/AppleMCP/.github/workflows/release.yml  # optional
unzip M3MCP.app.zip

# Point the MCP client at the bridge inside the bundle
claude mcp add applemcp /absolute/path/M3MCP.app/Contents/MacOS/M3MCPBridge

Candidate status. The automated build is Apple Silicon only (arm64), ad-hoc signed, and unnotarized. It is not a production-grade macOS distribution.

Verification has limits. The checksum detects a mismatch against the asset recorded in the same GitHub release; alone it does not establish independent publisher authenticity. GitHub provenance binds the ZIP to this repository's workflow, but does not replace Apple Developer ID signing and notarization.

Respect Gatekeeper. If macOS blocks the app, verify its origin first and use System Settings, Privacy & Security → Open Anyway only when you trust the candidate. Do not remove quarantine metadata merely to bypass the warning.

Privacy grants may need renewal after an update. The source installer below uses a stable local certificate to preserve a consistent development identity. Public production distribution still needs a protected Developer ID, hardened runtime, trusted timestamp, notarization, and stapling pipeline.

Setup

# Build (requires the macOS 26 SDK; deployment target remains macOS 15)
swift build
swift test

# Run the app
./script/build_and_run.sh

# Add to Claude Desktop (~/Library/Application Support/Claude/claude_desktop_config.json)
{
  "mcpServers": {
    "applemcp": {
      "command": "/path/to/AppleMCP/.build/debug/M3MCPBridge"
    }
  }
}

# Or add to Claude Code
claude mcp add applemcp /path/to/AppleMCP/.build/debug/M3MCPBridge

# Check the endpoint
curl --unix-socket ~/Library/Application\ Support/M3MCP/mcp.sock \
  http://localhost/health
